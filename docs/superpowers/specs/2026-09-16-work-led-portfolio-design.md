# 徐德明作品主导型个人网站设计说明

## 目标

将现有作品集从太空视频主导改为真实海尔作品主导。首屏直接说明徐德明的职业定位，并用真实项目画面建立可信度。

## 页面结构

页面顺序固定为：首页首屏、精选作品、案例拆解、视觉延展、关于与联系。三套重点作品保留完整长图、设计复盘展开、分类筛选和灯箱预览。

## 视觉规则

- 首屏使用深海军蓝背景与冰川蓝强调色，右侧展示真实海尔作品拼贴。
- 首屏之后切换为白色与浅冰川灰内容区，不再反复切换主题。
- 全站使用现代中文无衬线字体，不使用太空、紫色霓虹和装饰性滚动提示。
- 过程区使用冷蓝动态背景，所有过程图继续标注为“设计复盘示意”。
- 保留真实个人照片、真实联系方式和原始作品，不覆盖源素材。

## 交互规则

- 首屏作品卡片使用轻微悬停位移，帮助区分前后层级。
- 重点作品卡片可滚动到对应案例。
- 案例长图可打开灯箱并滚动查看。
- 过程图可展开与收起，图库可按类别筛选。
- 所有动画支持减少动态效果设置，手机端改为单列或双列布局。

## 验收标准

- 首屏不加载太空视频，并出现真实海尔作品拼贴。
- 精选作品位于关于区域之前。
- 页面不存在装饰性向下滚动提示。
- 生产构建和 Sites 测试通过。
- 桌面与 390 像素手机视口无横向溢出，控制台无错误。
